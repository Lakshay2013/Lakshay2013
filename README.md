## 💫 About Me

I build software that is meant to be used, not just written.

My work focuses on backend systems, APIs, and full-stack applications where reliability, performance, and clean architecture matter. I enjoy turning ideas into working products and building tools that make developers and teams more productive.

I work primarily with **JavaScript**, **Node.js**, **Express**, **MongoDB**, and **Python** — and spend a lot of time thinking about system design, scalable backend services, and how different pieces of software interact under real-world load.

Currently building **[Zyra](https://github.com/Lakshay2013/Zyra)** — a multi-tenant B2B SaaS LLM monitoring & middleware platform with async job queues, PII detection, token cost analytics, intelligent model routing, and a risk detection engine.
